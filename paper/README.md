# NAACL 2027 draft

This directory is a complete Overleaf-ready bundle. Upload all four source
files together, or upload `naacl2027-overleaf.zip` directly:

- `naacl2027_draft.tex` — main document
- `references.bib` — bibliography
- `acl.sty` — official ACL style
- `acl_natbib.bst` — official ACL bibliography style

The two ACL style files are unmodified copies from commit
`d5adc823ff0f80f98c80405ca0ab66c68e684409` of
<https://github.com/acl-org/acl-style-files>.

On Overleaf, set `naacl2027_draft.tex` as the Main document if it is not selected
automatically. The draft uses `\usepackage[review]{acl}` for anonymous review.
Change `review` to `final` only for the camera-ready version.
